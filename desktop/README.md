# 考研综合面板 · 桌面应用

基于 Tauri 2 的 Windows 应用，将上一级的 `考研综合面板.xlsx` 转为本地交互面板。无需 Excel，运行时无需联网。

开发者请从 [开发文档索引](docs/README.md) 阅读架构、数据字典、持久化与迁移、测试及发布流程；Excel 与桌面版的适用口径见 [面板构建说明](../面板构建doc.md)。

## 日常使用

运行 `../桌面应用/考研综合面板-1.9.0.exe`。交付目录只保留最新 exe。从底部标签或左上方下拉框选择工作表，在节点下方填写高于当前预测值且不超过 100 的掌握度。按 Tab、回车或点击其他位置提交，分数自动更新并保存。

更新约定（用户于 2026-10-03 授权）：以后旧版正在运行时，直接关闭旧版程序再替换，无需再次确认。优先正常关闭以完成待保存输入；保留学习记录，交付目录只保留最新版 exe。2026-10-12 补充：每次更新均创建或更新桌面“考研综合面板”快捷方式，指向最新版。

- 分数面板：完整保留 7 个板块、46 个小节、492 个节点，默认采用小节上下两行、节点横向排列；保留原表坐标、合并单元格及蓝色层级，408 的尺寸以数学面板为基准统一。
- 年度小节得分：保留两科 2016—2025 年数据及空白预留年份；已分析年份得分可以修改。408 年份权重可以调整。
- 考点分布：保留 736 条题目／小问、年度合计及原有来源和估分说明，只读。
- 自动保存：每次提交自动写入本地文件，progress.bak 保留上一份保存；异常恢复见数据文档。1.6.0 已移除导出备份、恢复备份和重新保存按钮。

原 38 张工作表保持相对顺序，408 分数面板后新增英语表，共 39 张。横向滚动查看后续节点，点击单元格后可在上方编辑栏查看完整文本或计算公式；地址框可跳转到可见单元格，如 `F5`。408 按原表冻结前五列。题目文字与计算公式只读。

1.0.1：408 分数面板统一采用数学面板的列宽、紧凑行高、字体与不换行样式，数学原有格式不变。两科节点名称平时裁切显示；点击后完整单行文字覆盖右侧单元格，点击其他单元格或按 Esc 后恢复。该显示调整不修改原工作簿、数值或学习记录。

## 显示记忆率（1.6.0）

数学、408 分数面板及英语表提供“显示记忆率”开关。开启后，掌握度格显示黑色掌握度和红色括号百分比，例如 40.55（60.11%）。未初学没有记忆率，括号显示 —。数学/408 掌握度仍显示两位小数，英语仍截断整数；记忆率统一显示两位小数。

点击格子编辑时只显示原始精度掌握度，结束编辑恢复组合显示，括号内容不参与输入、计算或存盘。组合文本在固定列宽内适配，不插行、不增宽，兼容错题三行。开关在本次运行中跨学习表沿用，重启默认关闭，不写入学习记录。年度和考点表不提供此按钮。

## 错题索引（1.4.0）

数学/408 分数面板点击“错题索引”后，每小节展开为节点名称、错题题号、掌握度三行；再次点击收起。题号初始为空，可填写“习题集 P028：003、7、12”等普通文本，支持清空，在单元格或上方编辑栏查看/编辑完整内容。

选中错题单元格，拖动右下角填充柄向右，将完整文本复制到同行右侧目标节点；纵向或向左拖拽不填充。空源可清空同行目标，预览边框标明填充范围。只对错题行提供填充柄。窄视图拖至左右边缘可横向滚动。

题号按原稳定节点 ID 保存，展开后的显示行号不作为存储键。录入和填充不改变掌握度、复习记录或分数。关闭重开与文件级恢复均保留内容；程序重新打开默认收起。历史 1.4.0 升级 v7→v8 只增加 492 个空文本字段，旧曲线保持原值，升级前独立备份 progress-before-wrong-index-v7.json。恢复不含题号的旧备份会将题号置空。完整说明见 [错题索引](docs/wrong-index.md)。

## 英语精读（1.2.0）

选择 408 分数面板后的“英语”工作表，点击“增加文章”，输入名称后新增一行，初始掌握度为 0。首次提高才记录初学；后续复用当前累积复习算法。文章名可在表内修改，改名不重置学习记录。

总掌握文章数 = 每篇文章的完整精度预测掌握度除以 100 后求和；总阅读词数 = 完整精度总掌握文章数 × 400。总掌握文章数显示两位小数；文章掌握度和总阅读词数直接截去小数显示整数，编辑时仍显示原值。文章及曲线随本地记录和自动文件备份保存。数学和 408 的既有显示规则不变。

升级到记录 v4 时保留两科所有参数、日期、年度输入和权重，只增加空英语列表；另存 `progress-before-english-v3.json`。完整合同见 [英语工作表文档](docs/english.md)。

## 遗忘与复习（1.5.0 累积复习算法）

算法依据 [遗忘曲线算法说明](../遗忘曲线算法说明.md)，按北京时间自然日计算。用户于 2026-10-03 确认：所有旧节点都视为没有学习记录，升级后从未初学、0 分开始；不把旧掌握度转换成虚构的学习日期。首次输入大于 0 的值时才初始化曲线，初始每日保留比例为 0.5，最近 5 次干预前历史为全零。初学不计入干预历史。

每日预测为 `baseMastery × retentionPerDay^经过天数`。例如初学填写 80，未复习则下一天为 40，再下一天为 20。按自然日跨午夜即计一天，不按满 24 小时计时。同日不自然衰减。

只有提高**当日未舍入的预测掌握度**才是一次复习。当前1.7.0将旧p换算为有效强度，乘本次增益后按复习前预测掌握度的平方根向初学强度回拉；r趋近0时新p趋近0.5。完整公式见算法说明。初学和每轮均为90%时，间隔1/1/1天后p=90%，1/2/5天后p=96%。同日提高从当天首次修改前快照重算，只计一次；初学当天只改R，p=0.5。

界面每 30 秒检查是否跨日，返回应用或重新打开时也会刷新。查询不会写回曲线起点，不会重复衰减。小节、板块与全科得分均使用当日曲线预测的完整精度数值；关闭期间也会遗忘，无需后台常驻。

每个已初学节点持久保存：初学日期、最近干预日期、曲线起始掌握度（0～1）、每日保留比例、最近 5 个 r、最近 5 次有效复习日期，以及最近复习前的曲线快照。未初学节点保存为 `null`。数据格式为 version 12，新版记录再次启动不会重新初始化。

边界处理：不创建起始掌握度为 0 的曲线；系统日期早于上次学习时拒绝复习，查询不向曲线起点之前外推。极端浮点情况若无法表示合法的 `0 < p < 1`，会明确报错并保留旧记录，不静默截断参数或强行设为 1。公式与当前算法文档一致。

恢复备份是恢复记录，不计为复习。新版备份保留原日期和参数；旧版 v1 备份仅迁移年度得分和权重，其节点按未初学处理，与本次升级约定一致。

1.1.1 升级：从最小值改为最近 5 次的算术平均值。2026-10-07 升级时核对的 5 个已学习节点均只有一次跨日复习，已准确重算；保留用户填写值和学习日期，更新每日保留比例及今日预测掌握度。version 2 升级前保留 `progress-before-mean-v2.json`，迁移后写入 version 3，重启不重复迁移。初学或仅初学当天复习的节点公式结果不变。旧版没有完整复习流水；对无法准确还原的复杂旧记录提示缺少历史并阻止覆盖，不凭空估算。导入 v2 备份遵循同一规则。

## 计算口径

**遵照 2026-10-01 用户补充要求，两科计算均保留完整精度，只在界面展示分值时保留两位小数。** 数学不再沿用工作簿的小节一位／节点两位逐级 ROUND，因而某些数学得分与原 Excel 有差异。两科原始年度数据下全部节点掌握度为 100 时均为 150.00。

小节分数 = Σ（有效年度小节得分 × 年份权重）÷ 权重合计；单节点分数 = 小节分数 ÷ 节点数；小节掌握得分 = Σ节点掌握度 × 单节点分数 ÷ 100；板块和全科逐级求和。计算使用 JavaScript 双精度数，不做中间舍入。可编辑输入保留原始精度。

**显示值绝不作为计算输入。** 单元格未编辑时显示两位小数，获得焦点后显示原始数值；失焦但没有修改时不会截断原值。存盘、恢复、年度加权、节点分数和各级总分均使用模型中的原始数值。例如 `73.123456789` 显示为 `73.12`，存盘与计算仍使用 `73.123456789`。权重编辑按百分数输入。

全科总分包含所有板块，不能直接与某个小节分数比较。某个小节全部为 100 时，该小节掌握得分等于其小节分数；其他小节有掌握度时，全科分数仍会更高。

数学保持原表 7 年固定权重；408 保持原表 9 年权重及归一化规则。预留年的空白与有效年份的 0 分严格区分，预留年不参与计算。年度小节得分仍是独立数据，不自动回写题目明细。

## 数据保存

Windows 正式应用保存到 `%APPDATA%\cn.kaoyan.study-panel\progress.json`。保存时先写临时文件，再替换正式记录；上次记录保留为同目录 `progress.bak`。若 Windows 重定向目录不支持重命名，保留旧记录备份后改用复制并刷新磁盘。关闭窗口前等待写入完成，保存失败会提示且阻止关闭。不要同时开启多个实例编辑同一份记录；从旧版切换到新版时先关闭旧版。

如记录损坏，界面停用编辑，避免覆盖原文件。可按数据文档恢复有效文件备份，或在关闭应用后复制 `progress.bak` 为 `progress.json`。旧版导出文件带有来源指纹，手动恢复前须核对来源一致，并提取其中 state；当前没有导入导出界面。

当前从 v1 迁移前，会额外保存 `progress-before-cumulative-v1.json`，后续日常保存不会覆盖它；年度得分和权重保留。原工作簿不会被修改，应用和 Excel 不自动同步。节点学习记录按上面的未初学规则初始化，后续以应用的本地曲线记录为准。浏览器开发预览使用 localStorage，和正式桌面数据分开。

```powershell
npm ci
npm test
npm run test:ui
npm run desktop:dev
npm run desktop:build
```

`npm run extract` 用 Python 标准库只读解析上一级工作簿，更新 `src/data.json`。仅在明确要更新源数据时执行；重新提取不会迁移现有应用记录，尤其不能未经映射调整节点地址。现有源文件 SHA-256 指纹记录在数据文件中。

测试覆盖：完整数量与年度题分分摊、0/50/100 掌握度、逐小节全掌握得分相等、两科全掌握 150、无中间舍入、年度输入依赖、408 权重归一化、空白年份、非法记录、精度在聚焦／失焦与保存重载后不变、自动文件备份与迁移、39 张工作表、英语新增与截断精度、原表合并布局、编辑栏、冻结列与窄窗口。

原生隔离验证：先执行 `npm run tauri -- build --no-bundle --config src-tauri/verification.conf.json`，再执行 `node scripts/native-smoke.mjs`。必须先完成隔离配置构建；脚本会启动目标 exe 后才断言标识，不能直接用正式 exe 运行。按上述顺序验证使用独立应用标识与隐藏窗口，不触及正式学习记录；验证后必须执行 `npm run desktop:build` 重新生成正式程序，不能分发验证版。

## 错题局部文字格式（1.9.0）

数学和408分数面板展开错题索引后，可在错题格内选中部分文字，按Ctrl+B或工具栏B切换加粗；点击“字体颜色”选择颜色，仅应用到该选区。颜色和粗体可以叠加；选择黑色恢复默认颜色。未选择错题格时格式控件禁用。

保持固定列宽、行高和选中后完整展开。普通文本仍保存在wrongQuestions，新增稀疏wrongQuestionFormats，格式片段为{text,bold?,color?}，拼接文本必须与对应题号完全一致；颜色仅#RRGGBB。没有格式的题号不占格式条目，删除全部格式文字或清空题号会清除其格式。保存结构化数据而非HTML，渲染时转义文本；粘贴外部内容按纯文本接入。

横向拖拽填充同时复制完整题号和格式，目标独立保存，之后修改目标不影响来源。文字/格式修改均不是学习或复习，不改变曲线、掌握度和分数；关闭重开保留。上方fx栏仍按纯文本编辑：替换内容时重置该格格式，未修改不重置。
