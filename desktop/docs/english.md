# 英语精读工作表（始于 1.2.0，当前 1.10.0）

2026-10-08 新增。英语表属于应用生成的工作表，不写入原 Excel 或 `src/data.json`。原 38 张表保持相对顺序，在 `408-分数面板` 后插入 `英语`，应用共 39 张表。

## 使用与布局

- A1 为“总掌握文章数”，B1 为统计值；C1 为“总阅读词数”，D1 为统计值。
- A2:B2 合并显示“文章”，C2 显示“掌握度”。第 3 行开始，每篇文章占一行，名称位于合并的 A:B，掌握度位于 C。
- 仅英语表工具栏显示“增加文章”。填写非空名称后新增文章，初始掌握度为 0，内部曲线为 `null`。取消或空白名称不增加记录。
- 初始列表为空，不把截图示例当成真实数据。新增后聚焦该行掌握度；可在名称格或编辑栏改名，改名保留原曲线。
- 允许同名文章，使用不同 ID 区分。当前不提供删除、排序或正文存储。

## 计算与显示

每篇文章复用 `memory.js` 的平均值遗忘算法，内部预测 `r_i(t)` 范围为 0～1。首次从 0 提高时初学，之后只允许高于当日完整精度预测的输入；按北京时间自然日衰减，关闭期间同样计时。

```text
文章显示前掌握度 = 100 × r_i(t)
总掌握文章数 = Σ r_i(t)
总阅读词数 = 总掌握文章数 × 400
```

| 字段 | 显示规则 |
| --- | --- |
| B1 总掌握文章数 | `toFixed(2)`，显示两位小数 |
| C 列文章掌握度 | `Math.trunc`，截去小数部分显示整数 |
| D1 总阅读词数 | `Math.trunc`，截去小数部分显示整数 |
| 编辑中的输入框／编辑栏 | 显示原始精度；未修改不截断保存、不计为复习 |

统计先对原始预测值求和，再乘 400，最后格式化。不能先截断每篇掌握度、或用已显示的 B1 乘 400。例如 88.999999 显示为 88，B1 显示 0.89，D1 显示 355；内部词数仍为 `(88.999999 / 100) * 400`。固定 400 是每篇文章的统计系数，不是读取正文得到的真实词数。

英语对预测数值的完整可往返十进制表示进行系数求和/缩放，不预先固定小数位、不加 epsilon；汇总后转回 Number。这样避免 `0.29 * 100` 的二进制运算噪声导致整数 29 被截成 28。遗忘曲线仍使用既有双精度算法和持久化参数，不改变其他科目的数值。

数学和 408 的显示规则不变，英语统计不计入两科考试得分。

同日再次提高覆盖当天结果，不追加历史；初学当天 p 保持 0.5。1.5.0 与两科节点共用累积复习公式，以相邻间隔、达到的掌握度和旧记忆率更新；历史 r 不再参与更新式。历史旧 r 保留，当前 p 按最近一次复习重算，统计随之更新。

## 数据与迁移

1.2.0 的学习记录 version 4 引入以下独立字段，当前 version 12 保留此结构：

```ts
english: {
  articles: Array<{
    id: string; // 新增时 crypto.randomUUID()，重命名不改变
    title: string; // 去除首尾空白后的非空名称
    memory: MemoryState | null; // 与科目节点相同的完整曲线字段
  }>;
}
```

数组顺序决定显示行号；ID 不依赖行号。日期、曲线参数、5 条 r、复习日期窗口及同日起点快照与文章名称一起保存，本地存档包含整个英语列表。非法名称、重复 ID 或非法曲线导致校验失败，不自动丢弃文章。

1.2.0 发布时 v3 → v4 仅增加空英语列表，数学/408 的 `memory`、`annual`、`weights` 完整保留，不重算、不清零。升级前首次另存 `progress-before-english-v3.json`（浏览器键 `kaoyan-panel-before-english-v3`）。v1/v2 先执行既有迁移语义，再增加空列表；当前 v4～v10 → v11 按记忆强度回拉算法重算最近一次 p 并保留旧 r，详见数据文档；v11 重开不重算。旧版备份不含英语文章，确认恢复后会清空当前英语列表，当前没有导入界面，手动恢复前请备份当前文件并核对状态。
