# 手动校正记忆率（1.13.0，记录v15）

选中数学、408或英语的掌握度格后，公式栏同时显示掌握度、记忆率输入和只读τ天数。记忆率按百分数输入（如80），回车或移开焦点保存；Esc取消。掌握度仍按原规则提高并计为复习。

修改记忆率是曲线校正，不新增复习。使用修改时完整精度掌握度q（0～1）和输入记忆率p（0～1），计算：

$$\tau=\left\lfloor\ln(q)/\ln(p)\right\rfloor,\quad R=1,\quad q_{新}=p^\tau$$

取整后面板同步更新：q=0.5、p=0.8得到τ=3天、掌握度51.2%。τ=0时掌握度为100%，次日起继续遗忘。记忆率严格大于0%且小于100%；未初学、实际预测值为0或反推日期超范围时拒绝修改，保留原记录。当前值只是显示为0但内部大于0时仍可计算。
