# 节点错题索引（1.4.0）

数学和 408 分数面板提供“错题索引”按钮。默认两行；展开后每小节依次为节点名称、错题题号、掌握度，中间行 E 列为表头，每个节点都有独立文本格。再次点击收起，列宽和冻结规则保持原样。英语与年度表不提供此功能。

题号初始为空，允许普通文本，例如“习题集 P028：003、7、12”。资料名、页码、前导零和标点原样保存，不按数值或公式解析。可在格内或上方编辑栏修改完整内容，允许清空。题号修改不触发复习，也不修改任何曲线参数或分数。

选中错题格，向右拖动右下角填充柄。边框预览目标范围，松开后将完整原文复制到同行右侧节点，覆盖目标文本。空源可清空目标。向左或纵向释放不填充；掌握度、节点名称、其他小节和无节点的预留格均不能成为填充目标。拖到视图边缘会横向滚动；Esc 可取消拖拽。

学习记录 version 8 新增 `wrongQuestions: Record<节点ID,string>`，含 492 个条目。身份仍来自原节点 ID，例如 math:F5；展开后的掌握度显示地址 F6、题号显示地址 F5 均绑定 math:F5，显示插行不改变学习记录。三行中的本表公式随显示行号更新，跨表年度引用不动。

历史 1.4.0 的 v7→v8 只增加空题号，不重算记忆率，保留 memory、english、annual 和 weights。首次迁移前保存 progress-before-wrong-index-v7.json，浏览器对应键 kaoyan-panel-before-wrong-index-v7。关闭重开和有效文件恢复均保留题号；程序重开默认收起。恢复不含题号的旧状态会置空题号；1.6.0 不再提供导入界面，手动恢复前需自行核对文件。

实现位于 model.js（校验与迁移）、workbook.js（显示插行及地址映射）、main.js（切换、文本编辑与拖拽）及原生保存层。验证见 tests/wrong-index.test.js、tests/wrong-index.spec.js 和 scripts/native-smoke.mjs；发布与快捷方式遵循[开发文档](development.md)。

1.5.0 发布时升级到 v9 会按累积算法重算最近一次记忆率，保留 v8 全部题号；备份改为 progress-before-cumulative-v<旧版本>.json，历史备份继续保留。详见 [数据与持久化](data-and-persistence.md)。

1.6.1：选中题号格时，输入框按完整内容向右展开并覆盖后方单元格视图；取消选中或按 Esc 收起。可在展开状态编辑，右下角填充柄仍在原格角落。覆盖处的相邻格仍可点击，同行拖拽填充通过原格坐标命中，不改变固定列宽、行高和存档。
