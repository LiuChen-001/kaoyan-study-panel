# 撤销与恢复（1.14.0）

Ctrl+Z撤销上一次已提交操作，Ctrl+Y恢复撤销的操作，最多保留最近10步。支持数学、408和英语的掌握度、手动记忆率，以及错题索引文字、加粗、颜色和横向填充。一次横向拖拽填充多个格算一步。无修改、校验失败、浏览和自动遗忘不计步。

输入框、公式栏、记忆率输入框或错题文字编辑区处于编辑焦点时，快捷键交由原生文字编辑器处理，不撤销已保存的学习操作。点击只读单元格或离开编辑框后使用操作撤销。撤销后进行了新的受支持修改，之前的恢复记录清空。

撤销/恢复直接还原该次操作前后的完整曲线或错题文字及格式，不调用复习算法，不创建新复习。还原曲线按当前北京时间预测掌握度，因此跨日撤销仍体现期间的遗忘。仅恢复本次操作涉及的字段，不回退之后新增的英语文章、文章标题、年度分数或权重。

撤销结果继续自动保存，关闭重开不会丢失；10步历史只保留在本次应用运行中，重开清空撤销队列。记录格式仍为v15，升级不迁移或重算既有曲线。

实现：history.js保存字段前后值及最多10步的双栈；main.js仅在成功提交后记步，全局快捷键在编辑器外执行。恢复先验证状态再移动历史栈，保存使用既有队列。测试覆盖10步上限、分支清空、完整曲线、格式及批量填充、编辑文字优先、英语和不相关字段保留、重开保存。
