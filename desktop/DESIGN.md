# 工作表界面

用户最终指定像打开 Excel 文件一样使用，默认保留原工作表横向上下两行架构，错题索引展开时每小节为三行。原 38 张表保持来源顺序，408 分数面板后插入英语表（共 39 张），底部工作表标签、上方编辑栏和地址框、行号、列字母、完整网格与横向滚动。

来源工作簿是视觉依据：从 OOXML 提取有效单元格颜色、字号、粗体、对齐、换行、行高、列宽、合并区域与冻结列。2026-10-03 用户指定 408 分数面板按数学的同类单元格统一列宽、行高、字体和对齐，不自动换行；数学原有格式保持不变，408 仍保留 A:E 冻结。两科节点名称平时裁切，选中时以不透明背景向右覆盖相邻单元格，显示完整单行文字而不改变尺寸；选择其他单元格或按 Esc 后恢复裁切。覆盖文字不拦截对后方单元格的点击。壳层使用浅灰蓝，不使用卡片、侧栏或折叠小节。

掌握度、已有年度小节得分和 408 年份权重可编辑，公式、节点文字和题目明细只读。选择边框与键盘焦点为深蓝。数学/408 计算值显示两位小数，节点数、题号与年份保留整数；输入获得焦点时显示原始精度。显示格式与数据模型严格分离。

窄窗口保留工作表比例及横向滚动，不改成竖向节点布局。工具栏提供学习表显示开关，保存状态与错误始终可见；不再显示导出、恢复、重新保存按钮。

英语表沿用蓝色网格：A1/B1 为总掌握文章数，C1/D1 为总阅读词数；第 2 行 A:B 合并为文章标题，C 为掌握度；每篇一行，名称 A:B 合并。英语专用“增加文章”按钮输入名称后新增 0 掌握度行，不预置示例文章。总文章数显示两位小数，掌握度与词数截去小数；编辑时保留原始精度。

数学/408 工具栏增加“错题索引”切换按钮，选中状态为既有浅蓝背景与深蓝边框。展开时名称/题号/掌握度上下三行，列宽保持固定；小节名称跨三行，分值表头跨上两行。题号格左对齐、不换行，输入或上方编辑栏可查看完整文本。填充柄仅在选中的错题格右下角出现，拖拽同行右侧目标以深蓝边框和浅蓝底预览，保留横向边缘滚动。收起与重新展开保留内容，重启默认收起。

显示记忆率开启时，掌握度只读呈现为黑色数值与 #c00000 红色括号百分比，两个部分同行显示。固定列宽内按实际文字宽度横向适配，避免裁切。焦点编辑只呈现原始掌握度，失焦恢复彩色只读显示；输入不包含百分比。未初学以—表示暂无记忆率。

错题题号格选中后，编辑框以白色原格背景单行向右完整展开，取消选中或 Esc 后恢复裁切。展开框可编辑，原格右下角填充柄位于其上；覆盖区的点击和填充仍按下面的实际网格单元格处理。保持固定列宽、行高和现有冻结规则。


1.9.0：错题格采用单行富文本编辑，选区Ctrl+B或紧凑B按钮加粗，工具栏“字体颜色”原生颜色选择器为选区设色。默认文字黑色/常规字重；其他单元格保持原有样式。两科工具栏提供相同控件，未选错题格时禁用，填充柄保持原位置。局部样式、选区与展开不能改变网格尺寸。


## 复习提示填充（1.10.0）

数学、408节点及英语文章的掌握度格按当前完整精度预测显示填充：已初学且0≤掌握度<30为淡红色#ffd9df；30≤掌握度≤50为橙色#ffe0b2；高于50沿用原格背景。未初学memory=null使用淡灰色#eeeeee，静态内容显示短横线“-”，不再显示0；即使开启显示记忆率，也只显示“-”。已初学后预测下溢为0仍属红色，不得误判为未初学。

单元格获得焦点仍以原始数值编辑，未初学编辑值为0，可输入更大值开始初学；未修改就离开恢复短横线，不产生学习记录。30/50阈值不使用显示舍入值，例如29.999999显示30.00但仍为红底，50.000001显示50.00但保持原背景。

跨北京时间自然日、重新聚焦、复习提交、切换/重开及错题两行/三行切换都会重新计算颜色；填充不改变列宽、行高、已有局部文字格式或分数公式。仅显示变化，算法和记录version12不变，不迁移或重算曲线参数。辅助说明通过掌握度输入的aria-description提供。测试见tests/review-cues.spec.js和native-smoke.mjs。
