# 考研综合面板
<!-- impeccable:product-schema 1 -->

## Platform
web

Tauri 2 Windows 桌面容器，离线使用。

## Users
使用现有数学（一）与 408 工作簿记录复习掌握度的考研学生。

## Product Purpose
保留科目 → 板块 → 小节 → 节点及年度小节得分、考点分布的架构。输入节点掌握度，自动计算得分并在本地保存。

## Capabilities and Constraints
用户选择默认保持 Excel 横向两行布局，错题索引展开后三行，界面像打开原工作簿。2026-10-01 用户明确修正：所有参与计算的数据始终来自完整精度数据，界面两位小数不回流参与计算。编辑时显示原始精度，未修改不得截断保存。不再采用数学原表 ROUND。不改写原工作簿。节点按下文遗忘模型初始化和迁移。
