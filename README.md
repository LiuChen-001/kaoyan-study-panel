# 考研综合面板

一个用于安排学习和复习的 Windows 桌面面板，包含数学（一）、408 和英语精读。界面沿用表格的横向布局：找到知识点，填写掌握度，程序自动计算得分，并随时间更新遗忘后的掌握度。

**第一次使用，请先阅读[《用户必读》](用户必读.md)**，了解分数从哪里来、掌握度与记忆率有什么区别。本 README 介绍平时如何操作。

当前桌面版：**1.10.0**。文档核对日期：2026-10-22。

## 下载和打开

1. 打开[桌面应用目录](桌面应用/)，下载 `考研综合面板-1.10.0.exe`。在 GitHub 网页中打开 exe 文件页后，点击 **Download raw file** 下载。
2. 在 Windows 中双击运行。无需安装 Excel、Node.js 或 Rust，程序运行时无需联网，也无需连接 Codex。
3. 可以为 exe 创建桌面快捷方式，或右键选择“固定到开始”。如果系统阻止自动固定，需要手动操作。

程序使用 Microsoft Edge WebView2。若无法启动，请检查系统是否已安装 WebView2 运行时。

只使用应用时，下载 exe 即可；不需要把整个源码项目下载下来。个人学习记录保存在本机，详见下文“保存、备份与更新”。

## 记录一次学习或复习

1. 用底部工作表标签或左上方下拉框，选择 `数学-分数面板` 或 `408-分数面板`。
2. 找到对应小节，向右滚动查看它的知识点节点。节点名称过长时，点击名称格可展开全文，也可在上方编辑栏查看。
3. 在节点下方的掌握度格输入普通数字，例如 **80 表示掌握度80%**，不要用 `0.8` 代替80。
4. 按 Tab、回车，或点击其他位置提交。右上角出现“**已保存到本机**”后，本次修改已保存。

未初学的节点显示灰底 `-`。第一次填写大于0且不超过100的值，表示初学该节点。此后只有完成复习，才把掌握度提高到新的自评值；新值必须严格高于当前预测值，且不超过100。程序不允许手工降低掌握度，下降由遗忘算法计算。

同一天多次提高，最新输入覆盖当天的记录，最多计一次复习；初学当天提高只调整初学掌握度。只点击、查看或未修改就离开，不算复习。

## 看颜色，安排复习

颜色按当前掌握度的完整精度判断：

| 掌握度格 | 含义 |
| --- | --- |
| 淡灰底、`-` | 尚未初学 |
| 红底 | 已初学，当前掌握度低于30 |
| 橙底 | 当前掌握度在30至50之间，含30和50 |
| 原背景 | 当前掌握度高于50 |

可以优先查看红色、橙色节点，结合实际做题情况安排复习。颜色是提示，不会自动替你提交复习记录；已学后遗忘到接近0的节点仍显示红底，不会变回未初学。

点击“**显示记忆率**”，掌握度格会同时显示黑色掌握度和红色括号记忆率，例如 `40.55（60.11%）`。前者是今天的掌握水平，后者表示每天保留前一天掌握度的比例。未初学仍只显示 `-`。这个开关重启后默认关闭。

掌握度按北京时间自然日更新，跨午夜即可变化，不需要等满24小时。关闭程序期间也会遗忘，下次打开会按实际日期重新预测。

## 使用错题索引

在数学或408分数面板点击“**错题索引**”，每个小节会展开为“节点名称／错题题号／掌握度”三行。中间一行可以填写普通文本，例如：

```text
高数习题集 P028：003、7、12
```

- 点击错题格后，长文字会向右展开显示；取消选中或按 Esc 后恢复裁切。
- 选中部分文字，按 **Ctrl+B** 或工具栏 **B** 切换加粗；用“**字体颜色**”设置选中文字的颜色。
- 拖动选中格右下角的小方块，向右复制到同行其他节点，文字和局部格式会一起复制。填充会覆盖目标原内容；空白源格可以清空目标。
- 填充只支持错题行内向右拖动，不支持纵向填充。

修改错题内容和格式不会触发复习，也不改变掌握度。上方 `fx` 编辑栏按纯文本编辑；在那里替换错题内容，会重置该格的局部加粗和颜色。

## 使用英语精读表

英语工作表位于408分数面板后。点击“**增加文章**”，输入文章名称后新增一行，初始状态为未初学 `-`；第一次提高掌握度才开始计时。文章名称可以修改，改名不会重置学习记录。掌握度的修改规则、遗忘算法及颜色提示与两科节点一致。

- 总掌握文章数＝每篇文章当前掌握度÷100后相加。
- 总阅读词数＝完整精度的总掌握文章数×400。

例如，一篇文章的掌握度为88，对统计贡献0.88篇、352词。这里的词数是按掌握度折算的指标，不是实际阅读次数或去重词汇量。

总掌握文章数显示两位小数；文章掌握度和词数截去小数部分显示整数。后台计算始终使用原始精度。

## 查看分数依据

`分数面板` 展示加权小节分数、单节点分数和掌握总分；`小节得分-年份` 展示该年各小节分得的真题分数；`考点分布-年份` 展示题号、归属小节和题分，可沿这条路径核对分数来源。

已分析年份的小节得分可以修改，修改后面板自动计算。408的年份权重也可调整，按百分数输入，例如9表示9%；数学当前采用固定权重。日常记录学习时通常只需要改节点掌握度和错题索引。

程序中没有直接导入大纲、自动分析新试卷、增加数学／408节点或编辑题目明细的功能。需要扩充内容时，请参考[面板构建说明](面板构建doc.md)。

## 保存、备份与更新

应用自动保存，当前记录位于：

```text
%APPDATA%\cn.kaoyan.study-panel\progress.json
```

可以把 `%APPDATA%\cn.kaoyan.study-panel` 粘贴到 Windows 文件资源管理器地址栏，打开记录目录。`progress.bak` 保留上一份保存，目录中还可能有升级前的独立备份。它们都不是完整的逐次学习流水。

- **备份或换电脑**：先正常关闭所有面板实例，再复制整个记录目录。只复制 exe 不会携带学习记录。
- **更新程序**：先关闭旧版并确认保存完成，再运行新版。学习记录按应用标识寻址，同一台电脑上更换 exe 位置不会自动清空记录。
- **避免同时编辑**：不要同时打开多个实例修改同一份记录，程序不会自动合并它们的输入。
- **保存或读取失败**：保留当前文件，按[数据与恢复文档](desktop/docs/data-and-persistence.md)核对备份；不要直接用空白记录覆盖。

当前没有“导出备份”“恢复备份”“重新保存”按钮，备份与恢复通过文件完成。原 Excel、分科工作簿和应用记录之间不自动同步。
