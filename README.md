# 考研面板

本目录是数学（一）和 408 专业课的 Excel 复习面板项目。它把考试大纲、历年真题考点分布、年度小节得分和节点掌握度组织在一起，供日常复习记录与分数统计使用，无需运行代码。

已新增基于 Tauri 的桌面应用，源码与使用说明见 [desktop/README.md](desktop/README.md)，Windows 程序位于 `桌面应用/`。桌面版保留原表 38 张工作表和横向上下两行布局，填写节点掌握度后自动保存。按照用户最新要求，**桌面版所有计算均使用原始精度数值，两位小数仅用于显示，不回流参与计算**；下文的数学逐级 ROUND 说明仍仅描述原 Excel。应用与 Excel 不自动同步。

桌面版 1.10.0 采用 [记忆强度回拉算法](遗忘曲线算法说明.md)：按北京时间自然日衰减，只允许提高完整精度预测掌握度，同日修改覆盖当天记录。每次间隔及复习后掌握度决定增益，旧记忆率承接历史；复习前掌握度越低，新记忆率越接近初学的0.5。初学和每轮均达到90%时，间隔1/1/1天三次复习后记忆率为90%，间隔1/2/5天后为96%。从更早算法升级时保留旧 r、输入、日期和错题文本，仅重算最近一次记忆率并刷新面板；1.9.0从v11升级只增加文字格式、不重算曲线；1.6.0 的视图升级不重算曲线；当前记录 v12。每次更新均替换程序及桌面快捷方式。Excel 本身不接入算法。

使用 Excel 时打开 [考研综合面板.xlsx](考研综合面板.xlsx)；使用桌面版时运行 `桌面应用/考研综合面板-1.10.0.exe`。本说明按 2026-10-01 的磁盘文件核对，当前综合工作簿有 **38 张工作表**。

桌面版新增 [英语精读工作表](desktop/docs/english.md)，位于 408 分数面板后，可增加文章并记录动态掌握度。应用共 39 张表，源工作簿仍为 38 张，英语数据独立保存在应用中。

数学/408 另支持 [错题索引](desktop/docs/wrong-index.md)：展开三行后逐节点填写资料名、页码和题号，可用右下角填充柄向右复制到同行节点，内容本地持久保存，不触发复习。

1.6.0 新增“显示记忆率”按钮：格内黑色掌握度后附红色记忆率，编辑保留原始精度。已移除导出备份、恢复备份、重新保存三个按钮，日常数据仍自动保存。

## 如何使用与计算

在对应分数面板中找到小节，横向查看节点文字，在节点下方的“掌握度（0~100）”行填写数字，例如 `80`。不要输入 Excel 百分比 `80%`，后者的实际数值为 0.8。

每个小节占两行：上行是字段标题和节点文字，下行是分数、节点数、单节点分数及对应掌握度。B、C、D 列与板块、全科总分是公式，日常只需填写节点下方的掌握度。

计算关系为：

1. **年度小节得分**：累加该年相关题目的分数；一道题涉及两个小节时各分一半。
2. **小节分数**：按指定年份权重计算年度小节得分的加权平均。
3. **单节点分数**：小节分数 ÷ 该小节节点数。
4. **板块掌握总分**：汇总板块内各节点的“掌握度 × 0.01 × 单节点分数”。
5. **全科总分**：汇总该科各板块掌握总分。

这些总分是基于历年考查分布和自评掌握度的复习指标；板块标题中的比例和卷面分值用于说明考纲结构，不用于强制缩放历史统计结果。

### 年份权重与精度

| 年份 | 数学 | 408 |
| --- | ---: | ---: |
| 2017 | 10% | 9% |
| 2018 | 不参与 | 9.5% |
| 2019 | 不参与 | 10% |
| 2020 | 12.5% | 10.5% |
| 2021 | 13.5% | 11% |
| 2022 | 14.5% | 11.5% |
| 2023 | 15.5% | 12% |
| 2024 | 16.5% | 13% |
| 2025 | 17.5% | 13.5% |
| 合计 | 100% | 100% |

- 数学权重直接写在各小节加权公式中。小节分数用 `ROUND(...,1)`，单节点分数用 `ROUND(...,2)`，沿用已有计算口径。
- 408 权重在 `408-分数面板!A60:B70`，其中 B61:B69 为可调整的年份权重，B70 为合计。小节和单节点分数分别显示一位、两位小数，底层计算保留完整精度。
- 因舍入口径不同，全部节点掌握度为 100 时，数学按现有公式合计为 150.04，408 为 150。不能为凑整数擅自修改某个节点的分数。

### 哪些修改会自动更新

| 修改内容 | 后续处理 |
| --- | --- |
| 节点掌握度 | 所属板块总分、全科总分自动更新。 |
| 年度“小节得分”数值 | 小节加权分数、单节点分数及掌握总分自动更新。 |
| 408 权重单元格 | 408 小节分数及其后续计算自动更新。 |
| 题目考点归类或题目分数 | **需重新汇总并写入对应年度小节得分表**；当前年度得分是静态数值，合并到同一文件后也不会自动汇总。 |
| 增删节点、小节或真题年份 | 更新节点计数、公式范围、年度映射和权重；保留已有节点的掌握度，并复核分数合计。 |

原始资料位于本目录之外：

- [2026 年考试大纲](../考纲/2026年/)：数学大纲、408 大纲及其他科目大纲 PDF。

题目分值以试卷标注为基础，未标明的小问分值采用估分，具体说明在对应年度考点分布表中。408 的 2021 年第 43 题已按核对来源采用 15 分，相关来源保留在该年说明中。

[数学/tmp/](数学/tmp/) 是历史构建留档，不是运行入口：

- `math/`：大纲条目、题目分析 JSON、布局清单和预览。`content.json` 是早期大纲转录数据，含首小节空占位，不能替代正式面板的完整节点内容。
- `math2017-2020/`、`math2021/`、`math2022-2025/`：分年份题目分析、检查记录、试卷提取文本、预览和历史工作簿。
- `scores2025/`、`scores2021-2024/`：年度得分汇总及文件修复的历史记录。
- `weighted-panel/`、`weighted-panel-recovery/`、`unit-precision/`：加权分数、写入恢复和单节点精度调整的历史记录。

其中 `original.xlsx`、`generated.xlsx`、`updated.xlsx`、`final.xlsx` 等名称只代表当时的处理阶段，均不作为当前正式入口。JSON 中的历史分析也可能早于后续修订，使用时以正式工作簿和原始资料核对。PNG 是预览／试卷页图，TXT 是提取文本，NDJSON 是检查输出。

2026-10-01 已清理该目录内 23 个一次性构建、修复、预览及检查代码文件；其中三份数据模块的内容转存为 `math/content.json`、`math/exams2017-2020.json` 和 `math/exams2022-2025.json`。历史工作簿、分析记录和预览仍保留。使用工作簿或已构建 exe 无需安装脚本依赖；开发环境另见桌面开发文档。

## 维护约定

- 修改前确认使用的是最新综合文件；备份应使用独立名称，避免覆盖日常填写的掌握度。
- 小节名称是题目归类与年度汇总之间的匹配键，应保持完整一致。
- 更新题目明细后，检查题型合计和全卷合计，再重新汇总年度小节分数；有效年份的小节得分合计应为 150。
- 综合文件内重命名工作表应通过 Excel 完成，让直接公式引用同步更新；删除年份表前先处理相关公式。
- 外部工具写入前关闭相应工作簿，写入后重新打开检查公式和显示。`~$` 开头的文件是 Excel 使用中的临时锁文件，不是项目正文，也不应手动清理正在使用的锁文件。
